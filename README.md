# Учимся печать на клавиатуре вместе с динозаврами!

Браузерная игра-тренажер для обучения печати на клавиатуре для маленьких детей

Для начала игры просто жми [сюда](index.html)

Делал для сына 6 лет, который очень любит динозавров и собирать пазлы🤗

После успешного прохождения урока малыш сможет сам собрать пазл. Для сборки пазла сначала выбрать мышкой элемент пазла внизу, затем выделить ячейку, где этот элемент должен находится (не drag&drop!).

Всего нужно пройти 10 классов как в школе, в каждом классе выполнить по 10 уроков с 16 уровнями каждый.

На прохождение каждого уровня дается 45 секунд и 3 жизни (изображения сердечек), можно установить режим с бесконечным количеством жизней, установив ``const SOFT_MODE = true;`` в файле js/lessons.js

После окончания 10 класса точно должна возрасти скорость печати на клавиатуре с раскладкой ЙЦУКЕН (QWERTY)🚀
